# Mandarin Tone Darts:
An application solely meant for Android devices, with the purpose of teaching students to learn the correct tones of Mandarin Chinese words.

## The game:
![The game.](.readme/game.gif "The game")

The four buttons at the bottom represent the four tones of Mandarin.

Read from left to right:
1. (ˉ / 1) A high, level pitch, like holding a note at a high point.
2. (´ / 2) A rising pitch, starting from a mid-level and going up.
3. (ˇ / 3) A dipping pitch, starting low, dipping even lower, and then rising again.
4. (ˋ / 4) A falling pitch, starting high and going down sharply.
